# AI Chatbot – Python, Gemini & Groq

## About This Project

This project is a Python-based AI chatbot that integrates different Large Language Models (LLMs), including Google Gemini and Groq.

The goal of this project is to explore how LLMs can be integrated into Python applications and how their capabilities can be extended using different features.

## What I Have Learned and Implemented

- Python programming and application development.
- Integration of different LLM providers, including Gemini and Groq.
- Working with different AI model personalities through system instructions.
- Integrating external APIs to retrieve real-time information.
- Implementing tool calling to allow LLMs to interact with external functions.
- Managing API keys using environment variables.
- Building interactive chatbot interfaces using Gradio.

## Development Approach

I experiment with different implementations, test my code using various example inputs and scenarios, identify errors, and make improvements before pushing changes to GitHub.

I use these projects to strengthen my practical programming skills and understand how AI-powered applications work.

## Technologies Used
